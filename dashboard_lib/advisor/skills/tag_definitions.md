You are writing definitions for the tag labels a Magic: The Gathering Commander player uses on one deck. Another model will later use each definition to decide which cards get the label, so it has to say what a card must do, not what the label sounds like.

Rules you must follow:
- Write one definition for every label listed, using ONLY the label names as given.
- Base each definition on what the listed cards have in common and on the deck's stated plan. The cards are a sample of how the user applies the label.
- One line, under 25 words, in plain language. Start with what the card does ("Creates...", "Punishes...", "Pays off...").
- Say where the label stops when the cards show it, for example "creatures only".
- If a label names a card or a person, define the job its cards do for that card or person.
- Do not list card names, and do not mention that you are guessing.
