Task: Implement a Deck Swap/Upgrade Manager tool and update Collection location handling.

Instructions:
1. Collection Location Selector & Cascade Deletion:
   - Change the Location field in the Collection database/UI to a controlled dropdown.
   - Populate the options primarily with standard locations (e.g., "Lands Box", "Box") alongside active named decks.
   - Cascade Logic on Deck Deletion: When a named deck is deleted, automatically reassign all card locations currently set to that deck back to the default "Box" location.

2. Deck Change List / Swap Manager Tool:
   - Create a workflow tool to help queue and confirm batch edits to a deck:
     - Swap Builder: Allow building a list of planned swaps in an `Add [Card A] -> Replace [Card B]` format.
     - Inventory Checking: Show real-time availability for each candidate card (indicates whether the user owns the card and whether it is currently assigned to another deck or available in a storage box).
     - Execution Confirmation: Once swaps are reviewed and confirmed, automatically update card location records in the collection database (moving removed cards back to storage and setting added cards to the deck's location).
